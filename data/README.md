# Datasets

Per-language descriptions, sources, licenses, and download instructions.

> **Variant A note.** Each language uses a *different* dataset. This is a
> deliberate trade-off — described in the thesis Limitations section — that
> means absolute metrics across languages are not directly comparable. The
> discussion focuses on **relative gains** (baseline → transformer) per language.

| Language | Dataset                                      | Loader function       | License        | Download |
|----------|----------------------------------------------|-----------------------|----------------|----------|
| English  | WELFake                                      | `load_welfake`        | CC BY 4.0      | HF mirror — auto |
| Russian  | Russian Troll Tweets + Lenta.ru news (composite) | `load_russian_fake_news` | CC0 + research | manual (Kaggle + HF/Kaggle) |
| Ukrainian| Ukrainian Fake and True News (Kaggle)        | `load_ufnd`           | see Kaggle page | Kaggle CLI |
| Chinese  | CHECKED (Weibo COVID-19 fake news)           | `load_weibo_rumor`    | academic research | auto from GitHub raw |

After all four are downloaded, splits are generated by
`src.data_utils.get_split(lang)` and persisted to `data/processed/<lang>/`.

## EN — WELFake

- **Source:** https://zenodo.org/record/4561253 (also mirrored on HF as
  `davanstrien/WELFake`).
- **Size:** ~72k articles, roughly balanced (real ≈ fake).
- **Format:** CSV with `title`, `text`, `label` (0 = real, 1 = fake on Zenodo).
- **License:** CC BY 4.0.
- **Auto-load.** `load_welfake()` first tries the HF mirror, then falls back to
  `data/raw/en/WELFake_Dataset.csv` if the mirror is unavailable.

To download manually:

```bash
mkdir -p data/raw/en
curl -L -o data/raw/en/WELFake_Dataset.csv \
  https://zenodo.org/record/4561253/files/WELFake_Dataset.csv
```

## RU — Russian Troll Tweets (fake) + Lenta.ru (real)

> **Why composite.** No clean single labelled fake/real Russian news dataset is
> reliably accessible. We approximate the task by treating IRA troll tweets
> (2012–2018, FiveThirtyEight) as **fake** and a sample of legitimate Lenta.ru
> articles as **real**. The loader filters troll tweets to `language='Russian'`
> and downsamples the larger class for balance.
> This domain mismatch (tweet vs news article) is documented in the
> Limitations section of the thesis.

### File 1 — Russian Troll Tweets

- **Source:** https://www.kaggle.com/datasets/fivethirtyeight/russian-troll-tweets
- **Size:** ~3M tweets in many languages; ~400k–600k Russian after filtering.
- **License:** CC0 1.0.

```bash
pip install kaggle               # one-time, see https://www.kaggle.com/docs/api
mkdir -p data/raw/ru
kaggle datasets download -d fivethirtyeight/russian-troll-tweets -p data/raw/ru --unzip
# the dataset contains several CSV chunks (IRAhandle_tweets_1.csv, ...).
# Concatenate or pick the largest, and save as `russian_troll_tweets.csv`:
python -c "
import pandas as pd, glob
df = pd.concat([pd.read_csv(f, low_memory=False) for f in glob.glob('data/raw/ru/IRAhandle_tweets_*.csv')], ignore_index=True)
df.to_csv('data/raw/ru/russian_troll_tweets.csv', index=False)
"
```

### File 2 — Lenta.ru news (real)

Several mirrors exist. Easiest:

- **HuggingFace:** `IlyaGusev/lenta` — `load_dataset('IlyaGusev/lenta', split='train[:30000]')`
  → save to CSV as `data/raw/ru/lenta.csv` with at least a `text` column.

```python
from datasets import load_dataset
ds = load_dataset('IlyaGusev/lenta', split='train[:30000]')
ds.to_csv('data/raw/ru/lenta.csv')
```

- **Kaggle alternative:** https://www.kaggle.com/datasets/yutkin/corpus-of-russian-news-articles-from-lenta
  → unzip → rename main CSV to `lenta.csv`.

After both files are in `data/raw/ru/`, the loader handles concatenation
and balancing.

## UK — Ukrainian Fake and True News (Kaggle)

- **Source:** https://www.kaggle.com/datasets/zepopo/ukrainian-fake-and-true-news
- **Topic:** Russo-Ukrainian war news (since 2022) — narrow domain.
- **Format:** CSV with text + fake/real labels.
- **License:** see Kaggle page.

> **Limitation.** This is the only publicly available labelled fake/real
> Ukrainian news dataset we could find; broader-topic Ukrainian fake-news
> data does not appear to exist publicly. The narrow war-focused domain
> should be discussed explicitly in the thesis Limitations section.

```bash
pip install kaggle
mkdir -p data/raw/uk
kaggle datasets download -d zepopo/ukrainian-fake-and-true-news -p data/raw/uk --unzip
mv data/raw/uk/*.csv data/raw/uk/ufnd.csv
```

The loader (`load_ufnd`) is column-name lenient: it accepts `text`/`content`/`body`/`article`
for text and `label`/`is_fake`/`fake`/`true`/`class` for the label.

## ZH — CHECKED (Weibo COVID-19 fake news)

- **Source:** https://github.com/cyang03/CHECKED
- **Size:** 344 fake + 1760 real microblogs. Small but high-quality
  expert-annotated.
- **Format:** CSV (also JSON) with `id`, `label` (`real`/`fake`), `text`,
  metadata.
- **License:** academic research use only.
- **Auto-download.** The loader fetches `dataset/fake_news.csv` and
  `dataset/real_news.csv` from `raw.githubusercontent.com` on first call
  if missing locally. No manual step required.

To pre-download manually:

```bash
mkdir -p data/raw/zh
curl -L -o data/raw/zh/fake_news.csv \
  https://raw.githubusercontent.com/cyang03/CHECKED/master/dataset/fake_news.csv
curl -L -o data/raw/zh/real_news.csv \
  https://raw.githubusercontent.com/cyang03/CHECKED/master/dataset/real_news.csv
```

## A note for the thesis Limitations section

This project hits real public-data gaps:

1. **No canonical labelled Russian fake-news dataset** exists on HuggingFace
   or Kaggle today; we approximate via troll tweets + legitimate news.
2. **Ukrainian labelled fake-news data is scarce** — the only accessible
   source covers war/politics only.
3. **Chinese options are small or behind forms** — CHECKED at 2.1k samples
   is the most accessible high-quality option; MCFEND (24k) requires form
   submission to authors.

These gaps are properties of the field, not project shortcomings, and
should be cited as such.
