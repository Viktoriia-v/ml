## 1. Цель работы

Реализовать и сравнить серию моделей классификации новостей (fake / real) для 4 языков: **английский, русский, украинский, китайский**. Модели идут от простых к сложным; для каждой считаются метрики и предоставляется объяснимость.

## 2. Главный исследовательский вопрос

Как меняется качество классификации fake/real news при переходе от простых моделей (TF-IDF + LR) к современным трансформерам и LLM, и какие закономерности при этом проявляются на разных языках.

## 3. Ограничения и важные оговорки

- **Датасеты — разные на каждом языке** (вариант A: отдельный лучший датасет под каждый язык). Это значит:
  - Прямое сравнение абсолютных метрик между языками **некорректно** (разные домены, разная сложность задачи).
  - В дискуссии работы сравнение языков формулируется через **относительный прирост** при переходе baseline → трансформер, а не через абсолютные числа.
  - Это ограничение нужно явно описать в разделе Limitations диплома.
- Кросс-языковой трансфер (train EN → test UK/RU/ZH) — **опциональный** эксперимент, выполняется только если останется время на 4-й неделе.

## 4. Датасеты

Найти и выбрать по одному датасету на каждый язык. Требования:
- Наличие меток fake / real
- Сбалансированность классов (или близко к ней)
- Разнородность тематик (не один домен)
- Размер: умеренный, без необходимости загружать сотни тысяч примеров

### Кандидаты для проверки доступности

| Язык | Кандидаты |
|------|-----------|
| Английский | WELFake, ISOT Fake News Dataset, FakeNewsNet, LIAR |
| Русский | Russian Fake News (Kaggle), FakeNewsRussia |
| Украинский | UFND (Ukrainian Fake News Dataset), наборы Texty.org.ua, проект «Брехня» / «По той бік новин» |
| Китайский | Weibo Rumor Dataset, MCFEND, CHEF |

### Что нужно зафиксировать по каждому датасету
- Источник, лицензия, ссылка
- Размер train/val/test split
- Распределение классов
- Средняя длина текста (важно для лимита 512 токенов у трансформеров)
- Домен / тематика

## 5. Модели

Финальный набор — 7 моделей × 4 языка = 28 экспериментов.

### 5.1. Baseline
- **TF-IDF + Logistic Regression** — на каждом языке отдельно

### 5.2. Классический ML
- **XGBoost** на TF-IDF признаках
- (SVM и Random Forest **исключены** — не дают принципиально нового сигнала поверх XGBoost, экономим время)

### 5.3. Нейросеть
- **BiLSTM** с предобученными FastText мультиязычными эмбеддингами
- (CNN исключён — оставляем одну архитектуру; в любом случае проиграет трансформерам)

### 5.4. Трансформеры
- **mBERT** (`bert-base-multilingual-cased`)
- **XLM-RoBERTa-base** (`xlm-roberta-base`)
- **XLM-RoBERTa-large** (`xlm-roberta-large`) — если позволят ресурсы; если нет, base достаточно

### 5.5. LLM
- **Zero-shot** классификация через API (Claude или GPT-4-class)
- **Few-shot** (3–5 примеров в промпте) через тот же API
- Опционально: одна open-source LLM (Qwen2.5-7B или Llama 3.1-8B) для сравнения proprietary vs open

## 6. Метрики

Для каждой модели на каждом языке посчитать:
- **Accuracy**
- **Precision** (macro и weighted)
- **Recall** (macro и weighted)
- **F1-score** (macro и weighted)
- **Confusion matrix** (с визуализацией)

Все результаты собрать в единую сводную таблицу: model × language × metric.

## 7. Объяснимость (Explainability)

| Уровень моделей | Метод объяснимости |
|-----------------|--------------------|
| TF-IDF + LR | Топ-N коэффициентов по классам, LIME для отдельных примеров |
| XGBoost | Feature importance (gain), SHAP для отдельных примеров |
| BiLSTM | LIME (или attention weights, если добавить attention layer) |
| Трансформеры | SHAP + attention visualization (BertViz) + интегрированные градиенты (Captum) |
| LLM | Объяснение решения через сам LLM («объясни, почему этот текст помечен как fake») + сравнение с тем, что выделил SHAP на трансформере |

Для финального диплома достаточно по 3–5 показательных примеров на каждый язык с визуализациями.

## 8. Технологический стек

- **Язык:** Python 3.10+
- **DL:** PyTorch, HuggingFace Transformers, HuggingFace Datasets
- **Классический ML:** scikit-learn, XGBoost
- **Объяснимость:** SHAP, LIME, Captum, BertViz
- **LLM API:** Anthropic SDK или OpenAI SDK (выбрать один)
- **Данные:** pandas, numpy
- **Визуализация:** matplotlib, seaborn, plotly (опционально)
- **Эксперимент-трекинг:** Weights & Biases (бесплатно для академии) или CSV-логи
- **Окружение:** Google Colab Pro+ (~$50/мес, A100 GPU) или RunPod почасово

## 9. Бюджет
